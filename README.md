# Verilog Digital Design

A structured collection of Digital Electronics and Verilog HDL implementations, covering fundamental logic gates, universal gates, combinational circuits, and sequential circuits.

## 📚 Contents

### 1. Logic Gates

* AND Gate
* OR Gate
* NOT Gate
* NAND Gate
* NOR Gate
* XOR Gate
* XNOR Gate

### 2. Universal Gates

* NAND Gate Implementations
* NOR Gate Implementations
* Basic Gates using Universal Gates

### 3. Combinational Circuits

* Half Adder
* Full Adder
* Ripple Carry Adder
* Multiplexer
* Demultiplexer
* Encoder
* Decoder
* Comparator

### 4. Sequential Circuits

* SR Latch
* D Latch
* SR Flip-Flop
* D Flip-Flop
* Registers
* Shift Registers

## 🛠️ Tools Used

* Verilog HDL
* Icarus Verilog
* GTKWave
* ModelSim
* Vivado
* Quartus II

## 🎯 Objective

To build a strong foundation in Digital Electronics and RTL Design through practical Verilog HDL implementation, simulation, and verification.

## 📈 Learning Progress

**Logic Gates → Universal Gates → Combinational Circuits → Sequential Circuits → Counters → FSM → Advanced RTL Design**
